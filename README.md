# Disk Cleaner

Disk space analyzer and cleaner for macOS 26 or later: scan a disk or folder, see what takes up space, and clean up caches, logs and build data.

## Install

```sh
brew install --cask thai1108/tap/disk-cleaner
```

Or download the DMG of the [latest release](https://github.com/thai1108/disk-cleaner-releases/releases/latest). The app is signed with Developer ID and notarized by Apple.
